## 产品边界

产品为交易研究与运营平台：受权用户上传 ITCH 记录、执行真实 C++ 确定性回放、查看结果及风险状态；管理员管理权限、风险配置、审计和发布。交易热路径独立于 Web、数据库、Redis 和任务队列。平台用户注册不赋予实盘交易权限。

会员等级与管理员权限分离；目前没有商业订阅或支付需求依据，因此不制造支付入口或收入数据。实盘能力必须有真实网关、行情、恢复和风险验收，缺失时明确禁用，不返回伪成功。

## 初始阻塞项

1. 没有历史代码或数据可供回归、迁移；建立新基线。
2. 外部接入尚未配置：合法 ITCH 来源、IBKR Gateway/账户、SMTP、正式域名与 TLS。
3. 发布需要独立 staging 验收、备份恢复和故障演练证据。
4. 当前不能宣称任何延迟目标、订单发送或实盘安全已经验证。

后续实现结果与剩余阻塞记录在 RELEASE_CHECKLIST.md 和 VERIFICATION.md；只有实际验证后更新状态。
