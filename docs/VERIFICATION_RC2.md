# v1.0.0-rc.2 自动交易成本与收益评估验收

日期：2026-11-01 UTC。结论：本地功能、真实服务联调与回归检查通过；**没有真实交易收益证据，未启用实盘，正式发布仍被安全及外部接入门槛阻断。**

## 本次实现

1. C++ 做市报价纳入每股费用、每单最低佣金、滑点缓冲和目标净边际；最低佣金按最小 1 股部分成交保守分摊，预计回扣不降低报价距离。
2. 模拟账户按每订单累计成交计收 `max(min_fee, cum_quantity × per_share_fee)`，后续部分成交只补差额；零成交不收费。
3. 独立 Paper runner 使用同一 C++ 成本约束。新 API 缺失、未配置成本或越界参数拒绝启用，首次 arm 后永久冻结，不能通过 Kill 后改参数绕过。
4. 新增 `/assessments/` 与版本化 API，保存不可变私有评估、拒绝重复行情累计和不同参数/模型混合，复核实际模拟输出的费用、库存和净盈亏。
5. 压力情景移除假设返佣并增加每成交股成本；无成交、未平仓、开放订单、无效估值、亏损及样本不足单独分类。正研究样本不等于盈利已证明；执行授权恒为 false。
6. 评估纳入账户导出与注销；敏感操作在账户锁内复核当前密码。新增 migration 0007、任务契约 4；旧参数任务和自动配置不会静默使用新报价模型。

独立审查发现并修复了最低佣金核验不足的问题：原先可能接受只扣每股费用、遗漏最低佣金的结果。新增有成交订单数量、费用下限、买卖成交/库存奇偶与最少订单数检查，原假正收益反例现被拒绝。

## 真实本地服务链路

最终镜像：`sha256:7ef1962f85f0b553b9e4bb08e1769c46ae6f1f05195561d50df283daa85d03d4`。

- 明确测试夹具执行 8 条行情回放及 12 条模拟消息；60 股合成成交产生 200 单位最低佣金（0.02 USD，测试假设），评估实际写入数据库。
- 期末活动订单使报告分类为 `open_exposure`，执行授权为 false。没有用正模拟金额掩盖未完成闭环。
- 应用数据库角色 DDL 被拒绝；临时测试账户、数据集、任务和评估在结束后清理。
- readiness 返回 200；应用、主机、PostgreSQL、Redis 四类监控目标全部 up。
- 新迁移后数据库再次备份并恢复至新建隔离库；迁移历史一致、pending migrations = 0；恢复库随后清理，未覆盖业务库。

部署中实际发生一次磁盘空间耗尽，容器替换被中断。清理可重新生成的未使用 Docker 构建缓存后恢复约 7 GB 空间，重新执行升级和以上冒烟检查全部成功；数据库与私有媒体卷保留。此环境使用会增加磁盘占用的容器存储方式，后续升级必须检查空间及 inode 余量，不应盲目清理业务卷。

## 性能与安全边界

新引擎完整文件基准保存于 `engine/benchmark/baseline-cost-aware-rc2.json`，记录硬件、输入/二进制 hash、100 次运行、分位数、失败数和确定性结果。它不是每 tick 延迟，更不是 IBKR/交易所 ACK 延迟。此前 rc.1 基准保留，不用不同负载下的单次数字宣传加速。

Trivy 0.76.1 对最终候选镜像复核：**0 Critical，46 High 包/CVE命中，10 个唯一 CVE，发布门槛未通过**。依赖未因本次功能更新而宣称已全面安全；原[安全报告](SECURITY_FINDINGS.md)的未修复项继续适用，没有增加忽略规则。

尚未完成官方 SDK/具体 Gateway 兼容性、真实 IBKR paper 账户/实时授权行情、行情恢复、端到端延迟、目标部署的 TLS/SMTP 与正式运营验收。没有真实收益、实盘盈利保证或隐式交易授权。

筛选后的证据位于 `docs/evidence/rc2/`；原始 `artifacts/` 含本地私有备份，不进入源码包。功能使用见[自动交易与收益验证](AUTOMATED_TRADING.md)。
