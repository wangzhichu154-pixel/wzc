# v1.0.0-rc.3：AI 训练与自动执行闭环实测

日期：2026-11-02 UTC。已实际编写代码、训练数值模型、执行 C++ 仿真和再训练、保存证据，并验证本地应用部署。**数据全部为明确声明的合成 ITCH；未连接真实 IBKR、未发送券商订单、未证明市场盈利。** 发布仍为候选版本。

## 交付代码

- `ml/`：数据核验、共享因果特征、Ridge 训练、JSON 推理、交易方向过滤、回测、模型注册与再训练。
- `engine/`：真实 ITCH 订单簿导出、独立 `trading-ml-replay`、默认拒绝的方向 gate、long-only 和成交/持仓统计。
- `execution/`：可选获批 AI 接入、最终同步 C++ 风控、现金预留、权限、私有成交与异常处理。
- `backend/`：只读 `/ai/` 和 `/api/v1/ai/status/`，真实版本/指标/失败门槛/再训练状态，服务端运营权限与脱敏。
- `requirements-ml.txt`、Docker、CI、只读模型挂载覆盖和操作文档；标准应用镜像没有 sklearn，训练独立运行。

## 实际回测结论

最终回测以 [final-backtest.json](evidence/rc3/final-backtest.json) 为准，来自第二轮模型，其五个 Python 源码指纹与最终交付一致。初次 8 月回测保留为追溯记录；随后修复的同时间戳及状态重置边界由专门的一致性回归覆盖。

预声明配置：单次最多 1 股、long-only、10 股硬库存、5 股软库存、每秒 5 个新订单、每日损失限额 100 USD、1 ms 模拟提交/撤单延迟、250 ms 信号 TTL；每股费用 0.0035 USD、每单最低 1 USD、每股滑点缓冲 0.002 USD。这些是**明确的研究示例值，不是 IBKR 费用承诺或已授权的资金限额**。最低佣金按最小一股部分成交分摊，保守性很强。

- 最终两个测试会话产生 19,212 条结构化状态：19,140 次预期收益不足以覆盖成本，72 次预热/重置。模型保持 WAIT。
- AI、成本感知双边基线、等待基线、双倍成本及五倍延迟情景均为 **0 成交、0 成交额、0 已实现盈亏、0 费用、0 期末库存和活动订单**。没有为了制造交易而调整阈值。
- 完整会话末尾 S/M、S/C 关闭市场，最终估值标志无效。因此汇总净盈亏、未实现盈亏和最大回撤明确为 `null`，不把陈旧标记值展示成有效收益。
- 没有闭合库存周期，平均持仓时间不可计算；没有提供资本基数，不编造收益率或换手率百分比。无交易样本无法校准真实成交概率、队列优先级或成本敏感性。
- 使用保守 displayed FIFO：延迟后看到的可见数量排在前方，前方撤单不信用，必须有后续同价 E/C 证据才可能成交；触价不是成交。保留撤单竞争、尾段成交和残余敞口。滑点缓冲用于扩展报价，并非校准后的真实市场冲击模型。
- 会话各自平坦起始，不强行清算残余库存，也不拼接为连续实盘收益曲线。按会话结果已记录；真实牛熊/高波动阶段的验证因缺少真实数据而**未执行**。

预测评估门槛通过不代表执行门槛通过。两模型都被模拟门槛拒绝；尝试 Paper 激活均明确得到 `Synthetic or unauthorized models can never enter broker paper`，见 [paper-recheck.json](evidence/rc3/paper-recheck.json)。没有活动指针，也没有实际券商查询或订单。

## 实测延迟与安全门槛

第二轮回放中，Python 特征计算加交易政策执行 19,212 次：P50 **21.482 μs**、P90 **38.418 μs**、P99 **76.716 μs**、P99.9 **271.219 μs**、Max **11.590 ms**。这是本环境离线进程测量，运行期间存在其他测试/构建负载；不是 NIC 到下单延迟，不含网络、券商、交易所 ACK，也不能据此承诺端到端亚毫秒。

新增固定训练依赖扫描未发现已知漏洞。候选镜像扫描仍发现 **0 Critical、46 High 包/CVE 命中、10 个唯一 CVE，均无扫描器提供的修复版本**；未加忽略规则，正式发布门槛仍阻断。最终镜像摘要与扫描汇总保存在 `evidence/rc3/security-summary.json`。

本地 HTTP 健康检查通过，匿名模型 API 返回 401；真实域名 HTTPS、SMTP、目标 Staging、官方 IBKR SDK/Gateway 兼容性、真实授权行情、现金字段/股票许可和受控 Paper 会话均**未执行**。旧数据库/媒体备份恢复流程保留，本次没有宣称重新完成完整生产灾备演练。

## 尚未完成的实盘条件

需要有合法权利且覆盖独立市场阶段的真实数据，重新训练和样本外评估；需要符合门槛的真实市场模型、受控 Paper 执行/恢复/对账验收，以及明确账户、标的、资金与风险额度授权。还需处理镜像安全与目标部署发布门槛。

当前实现始终拒绝 Live；它不是通过设置一个环境变量即可启用的实盘系统。实盘网关、权限、交易场所约束和真实端到端延迟必须另行验收。模型不会自行扩大限额、重置 Kill、审批自己的版本或保证盈利。
