# Production v1.0.0 Release Checklist

状态：**未批准正式发布**。本文件是验收清单，不是已通过声明。每个项目由负责人填写证据、版本、环境和日期。无法验证的项目标记 Blocked，不用“已配置”代替“已运行验证”。

当前为 rc.4 候选，最新证据见 [rc.4 验收](VERIFICATION_RC4.md)。正式发布仍被最终镜像安全及外部接入门槛阻断。

2026-11-01 候选本地证据：[实际验收记录](VERIFICATION.md)。已通过 SQLite 和真实 PostgreSQL/Redis 各 168 项应用测试、浏览器 7 尺寸 × 8 页、Docker 业务联调、四类指标抓取、数据库及私有媒体隔离恢复。上述局部证据不自动勾选完整生产门槛；[最终镜像仍有 10 个唯一 High CVE](SECURITY_FINDINGS.md)，此外真实 SMTP、TLS、生产目标与 broker 接入尚未验收。

## 产品与数据

- [ ] 范围和不支持能力在界面/文档中准确展示；未完成的实盘执行不得显示可用。
- [ ] 注册、验证、登录、登出、改密、重置、设备撤销与账号注销完整通过。
- [ ] 行情上传、私有访问、真实引擎回放、任务状态、失败重试、结果查询通过。
- [ ] 普通用户、会员、高级会员、管理员与超级管理员的 API/数据权限矩阵通过。
- [ ] 管理后台、反馈处理、公告、Feature Flag、操作审计通过。
- [ ] 数据导出、注销/删除与审计/备份保留政策一致。
- [ ] 隐私政策、用户协议、主体名称、支持联系方式和适用 Cookie 说明经确认。
- [ ] 付费若不在产品范围，明确不适用；若开放付费，真实回调签名、幂等、退款与对账必须验收。

## 工程与安全

- [ ] Unit、Integration、真实数据库/Redis 测试通过。
- [ ] E2E 覆盖完整关键流程及越权、失效会话、错误恢复。
- [ ] 1920×1080、1440×900、1366×768、1024×768、768×1024、390×844、375×667 响应式验证。
- [ ] 空库迁移和已有数据升级通过；migration drift 检查通过。
- [ ] runtime 数据库角色不能 DDL、提权或访问其他数据库。
- [ ] CSRF/XSS/SQL 注入/上传路径/对象级授权/限流测试通过。
- [ ] 密钥未入源码、镜像或日志，生产凭据与 Staging 隔离。
- [ ] 依赖与镜像扫描结果已处理；例外须有具体 CVE、风险依据、负责人和到期时间。
- [ ] Secret 与 token 轮换、会话失效、权限变更生效经过验证。
- [ ] 所有关键日志具有 request ID；敏感字段脱敏经过抽查。

## 部署与运维

- [ ] Staging 使用候选不可变镜像摘要完成实际部署；记录摘要和环境地址。
- [ ] HTTPS、证书链、TLS 版本、HTTP 跳转、代理信任边界验证。
- [ ] SMTP 真实投递与 outbox 重试验证。
- [ ] 前后台 readiness、worker 心跳、失败任务和队列行为验证。
- [ ] Prometheus 抓取、指标、告警通知与日志留存实际验证。
- [ ] 已执行数据库恢复；恢复报告可定位；业务数据查询和私有媒体恢复通过。
- [ ] 备份离机、加密、保留与删除政策配置，RPO/RTO 实测达到目标。
- [ ] 在约定并发和数据规模下记录 P50/P90/P99、错误率、资源和任务吞吐。
- [ ] 断开 Redis/数据库、worker 中断、磁盘不足、进程重启演练完成。
- [ ] 升级前确认容器存储、镜像/构建空间及 inode 余量，缓存清理与业务卷保留职责明确。
- [ ] Feature Flag 灰度、关闭功能、旧镜像回退及数据兼容验证。
- [ ] Production 域名、配置、镜像权限、邮件、备份、通知接收人已配置。
- [ ] 发布负责人确认全部关键门槛；更新 CHANGELOG 并记录发布窗口。
- [ ] 发布后真实健康检查、注册/登录/核心功能冒烟通过。

# rc.4 研究与恢复补充

2026-11-03 本地实测：408 pytest + 172 subtests、34 运维/安全 unittest、81 执行器测试和 C++ 5 suites 通过；20 个合成会话训练与回测、原请求恢复、rc.3/rc.4 模型库备份恢复、7 尺寸 AI 界面及真实数据库/Worker 联调完成。模拟仍以 `NO_FILLS` 拒绝，模型没有交易授权。

最终镜像有 45 High 命中、7 Unknown 严重度记录和独立上游规则命中，发布门禁拒绝。CI 已改为传递同一已验证镜像，远程 CI / Staging / Production 未执行。新增加入正式验收的必要条件：完整独立测试分区、成本和延迟压力底账、测试预留恢复、模型备份及指针隔离、证据与实际运行源码/镜像身份一致。上述工程测试不自动勾选真实行情、券商或盈利有效性。
